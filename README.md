# 智慧物业管理系统（终端版）

面向物业管理公司的**命令行信息化管理系统**：多小区、楼栋房屋、住户、物业费账单与缴费、欠费催缴、统计报表一站式管理。纯 Python 标准库 + SQLite，**零第三方依赖、无需联网、无需安装数据库**，单机即开即用。

## 功能总览

- **小区管理**：新增/修改/删除/模糊查询小区，切换当前小区；列表页展示每个小区的楼栋数、房屋数、在住人数与当前欠费总额。
- **楼栋与房屋管理**：楼栋增删改查；房屋登记与**按规则批量生成**（如"1# 楼 1 单元 1-18 层每层 4 户"一键生成 72 套）；多条件筛选（楼栋/单元/状态/户型/是否欠费/关键字）；房屋状态变更；**产权过户留痕**（旧业主自动转入历史轨迹）。
- **户型管理**：小区级户型库（室/厅/卫、面积、朝向、阳台/飘窗/入户花园），可被多套房屋复用；修改被引用户型时给出影响提示；户型分布统计。
- **住户管理**：以房屋为锚点登记**业主 / 家庭成员 / 租户**；身份证 18 位校验位校验、手机号 11 位校验；住户搬出/退租；**房屋历史住户轨迹**；按姓名/手机号/房号全局搜索；**导出住户通讯录 CSV**；车辆信息登记；租约到期提醒（30 天内到期高亮）。
- **物业收费（重点模块）**：
  - 收费项目配置：面积单价（元/㎡/月）、按户固定金额、按车位数量三种计价方式；月/季/年计费周期；启用/停用。
  - 账单生成：选择项目 + 账期，自动为范围内全部房屋生成账单，**生成前预览应收总额**，重复账单自动跳过。
  - 缴费登记：支持**部分缴费**，账单状态自动流转（未缴 → 部分缴纳 → 已缴清）；支持**一房多单一次缴清**；记录支付方式/收据号/经办人。
  - 账单金额调整：减免/优惠必须填写原因，**写入操作日志留痕**。
  - 欠费管理：欠费清单（含欠费天数、按日万分之五预估滞纳金，超 90 天醒目标红）；**导出催缴单 CSV**；模拟催缴短信。
  - 缴费记录：多条件组合查询完整流水，可导出 CSV。
- **统计报表**：账期/年度收缴报表（应收、实收、收缴率）、欠费金额 Top 10 房源、**各小区收缴率对比**，均支持导出 CSV。
- **扩展功能**：小区公告管理、报修登记与状态流转（待处理 → 处理中 → 已完成）。
- **系统工具**：数据库备份/恢复、操作日志查看、演示数据重置。

## 环境要求

- Python **3.10 及以上**（开发验证环境：3.12），无任何第三方依赖。

## 快速开始

```bash
cd property-management-system
python main.py
```

- 首次运行自动建库建表（`data/property.db`），并询问**是否载入演示数据**（2 个小区、每小区 3 栋楼 42 套房屋、40+ 位住户、500+ 笔账单与缴费记录、公告/报修/车辆一应俱全），可直接体验全部功能。
- 任何输入提示中键入 `q` 可取消当前操作；非法输入只会得到中文提示并要求重输，程序不会崩溃。

## 分模块操作手册

### 1. 小区管理

首次使用请先"新增小区"并设为当前小区（或"切换当前小区"）。之后所有模块只展示当前小区的数据。删除小区需二次确认，会级联删除该小区全部楼栋、房屋、住户关系、账单数据。

### 2. 房屋与户型管理

- **先建户型、再建楼栋、然后批量生成房屋**：选择楼栋 → 输入单元（可 a=全部单元）、楼层范围、每层户数 → 关联户型 → 确认后一键生成；房号规则为"楼层号+两位序号"（如 15 层 3 号 → 1503），已存在的房号自动跳过。
- 房屋列表支持按楼栋/单元/状态/户型/是否欠费/关键字筛选，输入序号可查看房屋详情（含在住住户与未缴账单）。
- 产权过户：选择新业主（已有住户档案或新建档案）→ 确认 → 旧业主记录自动转入历史轨迹，并写入操作日志。

### 3. 住户信息管理

- 业主入住：选择房屋 → 录入业主信息（身份证号自动校验校验位、可从证件号推算出生日期）→ 房屋状态自动置为"自住"。
- 同一房屋同时只允许一名在住业主与一名在住租户（业务约束，重复登记会得到明确提示）。
- 登记租户时若 30 天内到期会现场提醒；"租约到期提醒"菜单可统一查看。
- "导出住户通讯录 CSV"输出当前小区全部在住住户（含房号、类型、证件、紧急联系人等 16 列）。

### 4. 物业收费管理

- **收费项目**：面积单价填"元/㎡/月"；按户固定/按车位填"元/期"。有账单引用的项目不可删除，只能停用。
- **生成账单**：按车位计费的项目只为已登记车辆的房屋生成。生成前预览笔数与应收总额。
- **登记缴费**：选择房屋 → 列出未缴清账单 → 输入序号缴费（金额可改，支持部分缴费）；输入 `a` 可一次缴清该房全部账单。
- **账单调整**：输入调整后金额 + 必填原因，写操作日志留痕，账单状态自动重算。
- **欠费清单**：欠费天数按计费周期期末起算；超 90 天整行标红；滞纳金 = 欠费 × 日万分之五 × 天数（仅供参考）。
- **催缴**：可导出全部欠费的催缴单 CSV，或对单笔欠费生成催缴短信文本并可保存。

### 5. 统计报表

- 收缴率 = 实收总额 ÷ 应收总额 × 100%（按账单口径：账单归属账期的应收与该账单累计实收）。
- 年度报表按账期前缀汇总，兼容月（2026-09）/季（2026-Q3）/年（2026）三种账期。
- 各小区收缴率对比覆盖系统内全部小区。

### 6. 公告与报修 / 系统工具

- 公告：发布、查看、修改、删除。
- 报修：登记（可选关联房屋，支持公共区域）→ 状态流转 → 完成时记录处理人与结果、自动记录完成日期。
- 系统工具：备份（生成 `data/backups/property_时间戳.bak.db`）、从备份恢复、查看操作日志（删除小区/过户/调账/备份恢复等关键操作均留痕）、重置并重载演示数据。

## 数据存储与备份

- 全部数据存储于单文件 SQLite 数据库 `data/property.db`，重启程序数据不丢失。
- 程序内"系统工具 → 备份数据库"一键备份；恢复时选择备份文件并二次确认覆盖。
- 也可直接复制 `data/property.db` 文件进行冷备份；恢复时用备份文件覆盖同名文件即可。
- 导出的通讯录/催缴单/报表位于 `data/exports/`，CSV 使用 `utf-8-sig` 编码，Excel 直接打开不乱码。
